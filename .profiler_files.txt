## Quick Commands:

# Enable profiling
python3 main.py --debug

# View main report
cat DecompositionOUTPUT/Profiling/Profiling_Report.txt

# View specific stage
cat DecompositionOUTPUT/Profiling/Profiling_Onion3d.txt

# List all profiling files
ls DecompositionOUTPUT/Profiling/

# Open CSV in Python
python3 -c "import pandas as pd; print(pd.read_csv('DecompositionOUTPUT/Profiling/Profiling_Onion3d.csv'))"

# Clean profiling outputs
rm -rf DecompositionOUTPUT/Profiling/
